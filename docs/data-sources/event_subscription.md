# openmetadata_event_subscription Data Source

Looks up a single OpenMetadata event subscription by id or fully qualified name.

## Example Usage

```terraform
data "openmetadata_event_subscription" "finance_updates" {
  fully_qualified_name = "finance-updates"
}

output "finance_updates_subscription_id" {
  value = data.openmetadata_event_subscription.finance_updates.id
}
```

## Schema

### Optional

- `fully_qualified_name` (String) Event subscription fully qualified name. Exactly one of id or fully_qualified_name must be set.
