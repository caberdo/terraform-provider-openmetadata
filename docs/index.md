# openmetadata Provider

Manages OpenMetadata metadata. The provider talks to the OpenMetadata REST API
through the official Go SDK (`github.com/open-metadata/openmetadata-sdk/openmetadata-go-client`)
and targets OpenMetadata 1.13 and later.

## Authentication

The provider accepts either a bearer token or a username and password:

- `token` is a JWT or a personal access token and takes precedence.
- `username` and `password` are exchanged for a JWT through
  `POST /api/v1/users/login` on first use. The token is then cached for the
  lifetime of the provider process.

Every attribute has an environment fallback, so credentials can stay out of
version control:

| Attribute | Environment variable |
|-----------|---------------------|
| `host` | `OPENMETADATA_HOST` |
| `token` | `OPENMETADATA_TOKEN` |
| `username` | `OPENMETADATA_USERNAME` |
| `password` | `OPENMETADATA_PASSWORD` |
| `api_version` | `OPENMETADATA_API_VERSION` |
| `retry_count` | `OPENMETADATA_RETRY_COUNT` |
| `retry_wait` | `OPENMETADATA_RETRY_WAIT` |

The provider does not contact the server during `terraform validate` or
`terraform plan`; the login exchange happens when the first API call is made.

## Example Usage

```terraform
terraform {
  required_providers {
    openmetadata = {
      source = "caberdo/openmetadata"
    }
  }
}

# Credentials are read from OPENMETADATA_TOKEN, or from
# OPENMETADATA_USERNAME together with OPENMETADATA_PASSWORD, when the
# attributes below are omitted. Prefer the environment over committed values.
provider "openmetadata" {
  host = "https://openmetadata.example.com"
}
```

## Schema

### Optional

- `api_version` (String) OpenMetadata REST API version. Defaults to v1. Falls back to OPENMETADATA_API_VERSION.
- `host` (String) OpenMetadata server root including the scheme, for example https://openmetadata.example.com. Falls back to OPENMETADATA_HOST.
- `password` (String, Sensitive) Password for username. Falls back to OPENMETADATA_PASSWORD.
- `retry_count` (Number) Retries after the initial attempt for retryable responses (429 and 504). Defaults to 3. Falls back to OPENMETADATA_RETRY_COUNT.
- `retry_wait` (String) Delay between retries as a Go duration, for example 30s. Defaults to 30s. Falls back to OPENMETADATA_RETRY_WAIT.
- `token` (String, Sensitive) JWT or personal access token sent as a bearer token. Takes precedence over username and password. Falls back to OPENMETADATA_TOKEN.
- `username` (String) OpenMetadata user email used to obtain a JWT when token is unset. Falls back to OPENMETADATA_USERNAME.
