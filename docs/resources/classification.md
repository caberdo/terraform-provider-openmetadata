# openmetadata_classification Resource

Manages an OpenMetadata classification. Classifications group tags and can be marked mutually exclusive so an asset carries at most one tag from the classification.

## Example Usage

```terraform
resource "openmetadata_classification" "sensitivity" {
  name               = "Sensitivity"
  display_name       = "Data sensitivity"
  description        = "How sensitive an asset is."
  mutually_exclusive = true
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_classification.sensitivity 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a classification is its name.
terraform import openmetadata_classification.sensitivity Sensitivity
```

## Schema

### Required

- `name` (String) Classification name. Changing it replaces the classification, because the name is also its fully qualified name.

### Optional

- `description` (String) Markdown description of the classification.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `mutually_exclusive` (Boolean) When true, an asset may carry only one tag from this classification. Changing it replaces the classification.
