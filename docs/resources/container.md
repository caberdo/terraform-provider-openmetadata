# openmetadata_container Resource

Manages an OpenMetadata storage container. Containers are the buckets, directories and objects that live inside a storage service.

## Example Usage

```terraform
resource "openmetadata_storage_service" "buckets" {
  name         = "s3-bucket"
  service_type = "S3"
}

resource "openmetadata_container" "raw" {
  name        = "raw"
  service     = openmetadata_storage_service.buckets.name
  description = "Raw event archive."
}

resource "openmetadata_container" "events" {
  name         = "events"
  service      = openmetadata_storage_service.buckets.name
  parent       = openmetadata_container.raw.fully_qualified_name
  display_name = "Raw events"
  description  = "Raw events partitioned by day."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_container.events 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.parent.container.
terraform import openmetadata_container.events s3-bucket.raw.events
```
