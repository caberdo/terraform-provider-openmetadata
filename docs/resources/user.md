# openmetadata_user Resource

Manages an OpenMetadata user. Name, email, bot status and JWT expiry are fixed at creation and replace the user when changed.

## Example Usage

```terraform
resource "openmetadata_user" "jane" {
  name         = "jane.doe"
  email        = "jane.doe@example.com"
  display_name = "Jane Doe"
  description  = "Data engineer on the analytics platform team."
  is_admin     = false
  timezone     = "Europe/Amsterdam"

  teams = ["analytics"]
  roles = ["DataConsumer"]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_user.jane 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a user is its name.
terraform import openmetadata_user.jane jane.doe
```

## Schema

### Required

- `email` (String) Email address. The server restores the original value on update, so changing it replaces the user. Under basic authentication the email local part must equal name.
- `name` (String) User name and fully qualified name. It is immutable, so changing it replaces the user. Under basic authentication the server rewrites the name to the email local part, so configure both to agree.

### Optional

- `default_persona` (String) Fully qualified name of the persona shown by default for the user.
- `description` (String) Markdown description of the user.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `is_admin` (Boolean) Whether the user is an administrator. The server defaults this to false.
- `is_bot` (Boolean) Whether the user backs an OpenMetadata bot. The server fixes this at creation, so changing it replaces the user.
- `jwt_token_expiry` (String) JWT token expiry for a bot user, one of 1, 7, 30, 60, 90, OneHour or Unlimited. It is ignored for normal users and defaults to 7 for bots. The server fixes it at creation, so changing it replaces the user.
- `roles` (Set of String) Fully qualified names of the roles assigned to the user. The server returns roles sorted, so this is a set.
- `teams` (Set of String) Fully qualified names of the teams the user belongs to. The server returns teams sorted, so this is a set. Creating a user without teams assigns the Organization team; configuring teams replaces that assignment.
- `timezone` (String) IANA timezone of the user, for example Europe/Amsterdam.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For a user this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
