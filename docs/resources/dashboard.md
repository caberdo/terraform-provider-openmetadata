# openmetadata_dashboard Resource

Manages an OpenMetadata dashboard. A dashboard belongs to a dashboard service and can reference the charts and data models it renders.

## Example Usage

```terraform
resource "openmetadata_dashboard_service" "analytics" {
  name         = "analytics_dashboards"
  service_type = "CustomDashboard"
  description  = "Dashboard service owned by the analytics team."
}

resource "openmetadata_dashboard" "revenue" {
  name           = "revenue"
  service        = openmetadata_dashboard_service.analytics.fully_qualified_name
  display_name   = "Revenue"
  description    = "Monthly revenue dashboard."
  dashboard_type = "Dashboard"
  source_url     = "https://bi.example.com/dashboards/revenue"
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_dashboard.revenue 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c
# Or import by fully qualified name, which is the service name followed by the dashboard name.
terraform import openmetadata_dashboard.revenue analytics_dashboards.revenue
```

## Schema

### Required

- `name` (String) Dashboard name. Changing it replaces the dashboard, because the name is the suffix of its fully qualified name.
- `service` (String) Fully qualified name of the dashboard service that owns the dashboard. The service is fixed at creation, so changing it replaces the dashboard.

### Optional

- `charts` (List of String) Chart fully qualified names.
- `dashboard_type` (String) Kind of dashboard. One of Dashboard or Report.
- `data_models` (List of String) Dashboard data model fully qualified names.
- `description` (String) Markdown description of the dashboard.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `source_url` (String) URL of the dashboard in the source system.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name: the dashboard service name followed by the dashboard name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
