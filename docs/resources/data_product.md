# openmetadata_data_product Resource

Manages an OpenMetadata data product. A data product belongs to one or more domains and groups the assets it exposes.

## Example Usage

```terraform
resource "openmetadata_domain" "marketing" {
  name        = "Marketing"
  domain_type = "Consumer-aligned"
}

resource "openmetadata_data_product" "customer_insights" {
  name         = "CustomerInsights"
  display_name = "Customer Insights"
  description  = "Curated customer analytics data product."
  domains      = [openmetadata_domain.marketing.fully_qualified_name]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_data_product.customer_insights 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a data product is its name.
terraform import openmetadata_data_product.customer_insights CustomerInsights
```

## Schema

### Required

- `domains` (List of String) Fully qualified names of the domains that own the data product. At least one is required.
- `name` (String) Data product name. Changing it replaces the data product, because the name is also its fully qualified name.

### Optional

- `description` (String) Markdown description of the data product.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For a data product this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
