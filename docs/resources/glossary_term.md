# openmetadata_glossary_term Resource

Manages an OpenMetadata glossary term. Terms belong to a glossary and can be nested under a parent term.

## Example Usage

```terraform
resource "openmetadata_glossary" "finance" {
  name = "finance"
}

resource "openmetadata_glossary_term" "petty_cash" {
  glossary     = openmetadata_glossary.finance.name
  name         = "PettyCash"
  display_name = "Petty cash"
  description  = "Small cash expenses."
  synonyms     = ["cash on hand", "float"]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_glossary_term.petty_cash 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form glossary.term.
terraform import openmetadata_glossary_term.petty_cash finance.PettyCash
```

### Required

- `glossary` (String) Fully qualified name of the glossary that owns the term. Changing it replaces the term.
- `name` (String) Term name. Changing it replaces the term, because the name is part of its fully qualified name.

### Optional

- `description` (String) Markdown description of the term.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `mutually_exclusive` (Boolean) When true, a term may belong to only one glossary under the same parent. Changing it replaces the term.
- `parent` (String) Fully qualified name of the parent term for nested terms. Changing it replaces the term.
- `synonyms` (List of String) Alternative names for the term.
