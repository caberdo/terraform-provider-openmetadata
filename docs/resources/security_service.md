# openmetadata_security_service Resource

Manages an OpenMetadata security service. A security service connects a security policy source such as Ranger so its policies and tags can be ingested.

## Example Usage

```terraform
resource "openmetadata_security_service" "ranger" {
  name         = "ranger"
  service_type = "Ranger"
  display_name = "Ranger"
  description  = "Security service for the Ranger policy source."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_security_service.ranger 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a security service is its name.
terraform import openmetadata_security_service.ranger ranger
```
