# openmetadata_directory Resource

Manages an OpenMetadata drive directory. Directories form a tree inside a drive service and hold the files that live in that drive.

## Example Usage

```terraform
resource "openmetadata_drive_service" "shared" {
  name         = "google-drive"
  service_type = "GoogleDrive"
}

resource "openmetadata_directory" "root" {
  name        = "root"
  service     = openmetadata_drive_service.shared.name
  description = "Org-wide shared drive root."
}

resource "openmetadata_directory" "reports" {
  name         = "reports"
  service      = openmetadata_drive_service.shared.name
  parent       = openmetadata_directory.root.fully_qualified_name
  display_name = "Reports"
  description  = "Quarterly and annual reports."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_directory.reports 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.parent.directory.
terraform import openmetadata_directory.reports google-drive.root.reports
```
