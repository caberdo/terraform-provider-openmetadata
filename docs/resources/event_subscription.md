# openmetadata_event_subscription Resource

Manages an OpenMetadata event subscription. A subscription watches change events and delivers them to its destinations, such as the activity feed, Slack or a webhook.

## Example Usage

```terraform
resource "openmetadata_event_subscription" "finance_updates" {
  name         = "finance-updates"
  display_name = "Finance updates"
  description  = "Notifies the finance team when owned assets change."
  alert_type   = "Notification"
  enabled      = true
  resources    = ["table"]

  destinations = [
    {
      category = "Owners"
      type     = "ActivityFeed"
    },
    {
      category = "Teams"
      type     = "Slack"
      config = jsonencode({
        endpoint = "https://example.com/hooks/slack"
      })
    },
  ]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_event_subscription.finance_updates 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for an event subscription is its name.
terraform import openmetadata_event_subscription.finance_updates finance-updates
```

## Schema

### Required

- `alert_type` (String) Kind of alert the subscription evaluates. The server fixes it at creation, so changing it replaces the subscription.
- `destinations` (Attributes List) Destinations that receive matching events. Replacing the list sends the whole set through a single JSON Patch operation. (see [below for nested schema](#nestedatt--destinations))
- `name` (String) Subscription name. Changing it replaces the subscription, because the name is also its fully qualified name.
- `resources` (List of String) Entity types the subscription watches, for example table or testCase. Notification subscriptions require exactly one resource.

### Optional

- `description` (String) Markdown description of the subscription.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `enabled` (Boolean) Whether the subscription is active. Defaults to true.
- `poll_interval` (Number) Seconds between polling runs for observability subscriptions. The server default applies when omitted.
- `retries` (Number) Delivery retries before an event is dropped. The server default applies when omitted.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For an event subscription this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.

### Nested Schema for `destinations`

- `category` (String) Audience of the destination, for example Followers, Owners or Teams.
