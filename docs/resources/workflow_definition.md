# openmetadata_workflow_definition Resource

Manages an OpenMetadata workflow definition. A workflow definition wires nodes and edges to a trigger and drives automations such as approval flows.

## Example Usage

```terraform
resource "openmetadata_workflow_definition" "contract_approval" {
  name               = "contract_approval"
  display_name       = "Contract approval"
  description        = "Approval workflow used by the data contract review process."
  type               = "noOp"
  store_stage_status = false
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_workflow_definition.contract_approval 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a workflow definition is its name.
terraform import openmetadata_workflow_definition.contract_approval contract_approval
```

## Schema

### Required

- `description` (String) Markdown description of the workflow definition. The API requires it, so it has no default.
- `name` (String) Workflow definition name. Changing it replaces the definition, because the name is also its fully qualified name.

### Optional

- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `edges` (String) Workflow edges as a JSON array of objects with from and to nodes, plus an optional condition.
- `nodes` (String) Workflow nodes as a JSON array. Each node carries at least name and type; the accepted properties depend on the node type.
- `store_stage_status` (Boolean) Whether the workflow stores the status of every stage it runs.
- `trigger` (String) Workflow trigger as a JSON object with a type and a type-specific config.
- `type` (String) Workflow kind: eventBasedEntity or noOp. The API does not return it on read, so it is not computed.

### Read-Only

- `deployed` (Boolean) Whether the workflow definition is deployed on the server.
- `fully_qualified_name` (String) Fully qualified name. For a workflow definition this equals name.
- `id` (String) Server-assigned UUID.
- `suspended` (Boolean) Whether the workflow definition is suspended on the server.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
