# openmetadata_metadata_service Resource

Manages an OpenMetadata metadata service. A metadata service connects OpenMetadata to an external metadata source such as Atlas or Collibra.

## Example Usage

```terraform
resource "openmetadata_metadata_service" "elastic" {
  name         = "elastic-metadata"
  service_type = "MetadataES"
  display_name = "Elasticsearch metadata"
  description  = "Metadata service for the external metadata source."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_metadata_service.elastic 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a metadata service is its name.
terraform import openmetadata_metadata_service.elastic elastic-metadata
```

## Schema

### Required

- `name` (String) Metadata service name. Changing it replaces the service, because the name is also its fully qualified name.
- `service_type` (String) OpenMetadata metadata service type such as MetadataES, Atlas, Alation or Collibra. The server fixes it at creation, so changing it replaces the service.

### Optional

- `description` (String) Markdown description of the metadata service.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For a metadata service this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
