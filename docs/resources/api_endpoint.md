# openmetadata_api_endpoint Resource

Manages an OpenMetadata API endpoint. An endpoint is one operation of an API collection and inherits the collection's service.

## Example Usage

```terraform
resource "openmetadata_api_service" "payments" {
  name         = "payments-api"
  service_type = "Rest"
}

resource "openmetadata_api_collection" "pets" {
  name         = "pets"
  service      = openmetadata_api_service.payments.name
  endpoint_url = "https://api.example.com/v1"
}

resource "openmetadata_api_endpoint" "list_pets" {
  name           = "list-pets"
  api_collection = openmetadata_api_collection.pets.fully_qualified_name
  request_method = "GET"
  endpoint_url   = "https://api.example.com/v1/pets"
  display_name   = "List pets"
  description    = "Returns every pet known to the service."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_api_endpoint.list_pets 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.collection.endpoint.
terraform import openmetadata_api_endpoint.list_pets payments-api.pets.list-pets
```

## Schema

### Required

- `api_collection` (String) Fully qualified name of the parent API collection. Changing it replaces the endpoint.
- `name` (String) Endpoint name. Changing it replaces the endpoint, because the name is part of its fully qualified name.

### Optional

- `description` (String) Markdown description of the endpoint.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `endpoint_url` (String) URL of the endpoint relative to the collection root.
- `request_method` (String) HTTP method of the endpoint. Defaults to GET.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name, in the form service.collection.name.
- `id` (String) Server-assigned UUID.
- `service` (String) Fully qualified name of the API service, derived by the server from the collection.
- `service_type` (String) OpenMetadata API service type, derived by the server from the collection.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
