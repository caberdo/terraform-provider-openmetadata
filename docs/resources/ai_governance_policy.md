# openmetadata_ai_governance_policy Resource

Manages an OpenMetadata AI governance policy. A policy declares the category of AI governance rule, how strictly it is enforced, and whether it is active.

## Example Usage

```terraform
resource "openmetadata_ai_governance_policy" "bias_review" {
  name              = "bias-review"
  display_name      = "Bias review"
  description       = "Flags AI models whose bias score exceeds the review threshold."
  policy_type       = "BiasThreshold"
  enforcement_level = "Advisory"
  enabled           = true
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_ai_governance_policy.bias_review 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for an AI governance policy is its name.
terraform import openmetadata_ai_governance_policy.bias_review bias-review
```

## Schema

### Required

- `name` (String) Policy name. Changing it replaces the policy, because the name is also its fully qualified name.
- `policy_type` (String) Policy category such as BiasThreshold, ComplianceCheck, CostControl, DataAccess, ModelApproval, PerformanceStandard or SecurityControl.

### Optional

- `description` (String) Markdown description of the policy.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `enabled` (Boolean) Whether the policy is active. Defaults to false.
- `enforcement_level` (String) How strictly the policy is enforced: Advisory, Warning or Blocking. The server default applies when omitted.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For an AI governance policy this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
