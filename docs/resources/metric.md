# openmetadata_metric Resource

Manages an OpenMetadata metric. A metric records a named calculation, its type, its unit and the granularity it is computed at.

## Example Usage

```terraform
resource "openmetadata_metric" "weekly_revenue" {
  name                = "WeeklyRevenue"
  display_name        = "Weekly revenue"
  description         = "Revenue grouped by week."
  metric_type         = "SUM"
  unit_of_measurement = "DOLLARS"
  granularity         = "WEEK"
  expression_code     = "sum(revenue)"
  expression_language = "SQL"
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_metric.weekly_revenue 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a metric is its name.
terraform import openmetadata_metric.weekly_revenue WeeklyRevenue
```

## Schema

### Required

- `name` (String) Metric name. Changing it replaces the metric, because the name is also its fully qualified name.

### Optional

- `custom_unit_of_measurement` (String) Free-form unit used when unit_of_measurement is OTHER.
- `description` (String) Markdown description of the metric.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `expression_code` (String) Code that computes the metric. Requires expression_language. Removing it replaces the metric.
- `expression_language` (String) Language of expression_code: SQL, Python, Java, JavaScript or External. Removing it replaces the metric.
- `granularity` (String) Time granularity the metric is computed at, for example DAY or HOUR.
- `metric_type` (String) Calculation performed by the metric, for example COUNT, SUM or AVERAGE.
- `unit_of_measurement` (String) Unit reported by the metric, for example COUNT, DOLLARS or PERCENTAGE.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For a metric this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
