# openmetadata_ml_model Resource

Manages an OpenMetadata ML model inside an ML model service. ML models record the trained artifact, its algorithm and the features it consumes.

## Example Usage

```terraform
resource "openmetadata_ml_model_service" "mlflow" {
  name         = "mlflow"
  service_type = "Mlflow"
  display_name = "MLflow"
  description  = "ML model service for the experiment tracking server."
}

resource "openmetadata_ml_model" "churn" {
  name         = "ChurnModel"
  service      = openmetadata_ml_model_service.mlflow.fully_qualified_name
  algorithm    = "linear_regression"
  display_name = "Churn model"
  description  = "Predicts whether a customer will churn."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_ml_model.churn 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.name.
terraform import openmetadata_ml_model.churn mlflow.ChurnModel
```

### Required

- `name` (String) ML model name. Changing it replaces the ML model, because the name is part of its fully qualified name.

- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
