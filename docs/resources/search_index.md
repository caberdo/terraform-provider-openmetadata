# openmetadata_search_index Resource

Manages an OpenMetadata search index. A search index belongs to a search service and owns the ordered list of fields that describe its documents.

## Example Usage

```terraform
resource "openmetadata_search_service" "elastic" {
  name         = "elastic"
  service_type = "ElasticSearch"
}

resource "openmetadata_search_index" "messages" {
  name         = "messages"
  service      = openmetadata_search_service.elastic.name
  display_name = "Messages"
  description  = "Search index for application messages."

  fields = [
    {
      name      = "message"
      data_type = "TEXT"
    },
  ]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_search_index.messages 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.index.
terraform import openmetadata_search_index.messages elastic.messages
```
