# openmetadata_test_case Resource

Manages an OpenMetadata test case. A test case binds a test definition to an entity such as a table and records the pass or fail status of each run.

## Example Usage

```terraform
resource "openmetadata_database_service" "warehouse" {
  name         = "warehouse"
  service_type = "Postgres"
}

resource "openmetadata_database" "analytics" {
  name    = "analytics"
  service = openmetadata_database_service.warehouse.name
}

resource "openmetadata_database_schema" "public" {
  name     = "public"
  database = openmetadata_database.analytics.fully_qualified_name
}

resource "openmetadata_table" "users" {
  name            = "users"
  database_schema = openmetadata_database_schema.public.fully_qualified_name
  description     = "One row per registered user."

  columns = [
    {
      name             = "id"
      data_type        = "BIGINT"
      description      = "Primary key."
      ordinal_position = 1
    },
    {
      name             = "email"
      data_type        = "VARCHAR"
      data_length      = 255
      ordinal_position = 2
    },
  ]
}

# tableRowCountToBeBetween is a built-in definition, so no test_definition
# resource is needed. Use an openmetadata_test_definition resource to register
# a custom SQL test instead.
resource "openmetadata_test_case" "users_row_count" {
  name            = "users_row_count"
  entity_link     = "<#E::table::${openmetadata_table.users.fully_qualified_name}>"
  test_definition = "tableRowCountToBeBetween"
  display_name    = "Users row count"
  description     = "Fails when the users table holds fewer than 100 or more than 1000000 rows."

  parameter_values = [
    {
      name  = "min"
      value = "100"
    },
    {
      name  = "max"
      value = "1000000"
    },
  ]

  compute_passed_failed_row_count = true
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_test_case.users_row_count 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, assigned by the server when the test case
# is created.
terraform import openmetadata_test_case.users_row_count warehouse.analytics.public.users.users_row_count
```

## Schema

### Required

- `entity_link` (String) Entity the test runs against, in the form <#E::table::service.database.schema.table>. Changing it replaces the test case.
- `name` (String) Test case name. Changing it replaces the test case.
- `test_definition` (String) Fully qualified name of the test definition, for example tableRowCountToBeBetween. Changing it replaces the test case.

### Optional

- `compute_passed_failed_row_count` (Boolean) When true, the server also counts passing and failing rows.
- `description` (String) Markdown description of the test case.
- `dimension_columns` (List of String) Columns used to group the test results into dimensions.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `parameter_values` (Attributes List) Parameters passed to the test definition, for example min and max for a row-count test. (see [below for nested schema](#nestedatt--parameter_values))
- `top_dimensions` (Number) Number of top dimensions kept in the test results. The server default applies when omitted.
- `use_dynamic_assertion` (Boolean) When true, the test definition evaluates rows dynamically instead of using a single query for the whole table.

### Read-Only

- `entity_fqn` (String) Fully qualified name of the entity under test.
- `fully_qualified_name` (String) Fully qualified name assigned by the server.
- `id` (String) Server-assigned UUID.
- `test_case_status` (String) Result of the latest run, for example Success, Failed or Aborted.
- `test_suite` (String) Fully qualified name of the test suite that owns the test case.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
