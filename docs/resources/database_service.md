# openmetadata_database_service Resource

Manages an OpenMetadata database service. Database services are the connection containers for databases, schemas and tables.

## Example Usage

```terraform
resource "openmetadata_database_service" "warehouse" {
  name         = "warehouse"
  service_type = "Postgres"
  display_name = "Warehouse"
  description  = "Database service for the analytics warehouse."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_database_service.warehouse 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which for a database service is its name.
terraform import openmetadata_database_service.warehouse warehouse
```

## Schema

### Required

- `name` (String) Database service name. Changing it replaces the service, because the name is also its fully qualified name.
- `service_type` (String) OpenMetadata service type such as Postgres, Mysql, BigQuery, Snowflake. The server fixes it at creation, so changing it replaces the service.

### Optional

- `description` (String) Markdown description of the database service.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.

### Read-Only

- `fully_qualified_name` (String) Fully qualified name. For a database service this equals name.
- `id` (String) Server-assigned UUID.
- `updated_at` (String) Last update time in RFC 3339 format.
- `updated_by` (String) User that performed the last update.
- `version` (Number) Server-side entity version.
