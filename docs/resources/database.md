# openmetadata_database Resource

Manages an OpenMetadata database inside a database service. Databases group the schemas that hold tables, stored procedures and queries.

## Example Usage

```terraform
resource "openmetadata_database_service" "warehouse" {
  name         = "warehouse"
  service_type = "Postgres"
}

resource "openmetadata_database" "sales" {
  name         = "sales"
  service      = openmetadata_database_service.warehouse.name
  display_name = "Sales"
  description  = "Sales transactional database."
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_database.sales 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, in the form service.database.
terraform import openmetadata_database.sales warehouse.sales
```
