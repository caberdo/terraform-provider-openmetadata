# openmetadata_ingestion_pipeline Resource

Manages an OpenMetadata ingestion pipeline: the workflow definition that reads metadata, usage, lineage or profiling data from a service.

## Example Usage

```terraform
resource "openmetadata_database_service" "warehouse" {
  name         = "warehouse"
  service_type = "Postgres"
  display_name = "Warehouse"
  description  = "Database service for the analytics warehouse."
}

resource "openmetadata_ingestion_pipeline" "metadata" {
  name           = "warehouse_metadata"
  display_name   = "Warehouse metadata ingestion"
  description    = "Ingests databases, schemas and tables from the warehouse service."
  service        = openmetadata_database_service.warehouse.fully_qualified_name
  service_type   = "databaseService"
  pipeline_type  = "metadata"
  source_config  = jsonencode({ type = "DatabaseMetadata" })
  airflow_config = jsonencode({ scheduleInterval = "0 * * * *" })
  logger_level   = "INFO"
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_ingestion_pipeline.metadata 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which is <service>.<pipeline name>.
terraform import openmetadata_ingestion_pipeline.metadata warehouse.warehouse_metadata
```

## Schema

### Required

- `name` (String) Ingestion pipeline name.
- `pipeline_type` (String) Workflow kind such as metadata, profiler or lineage. The server fixes it at creation, so changing it replaces the pipeline.
- `service` (String) Fully qualified name of the service this pipeline ingests from. The server fixes it at creation, so changing it replaces the pipeline.

### Optional

- `airflow_config` (String) Airflow scheduling configuration as a JSON object string, for example {"scheduleInterval": "0 * * * *"}.
- `description` (String) Markdown description of the pipeline.
- `display_name` (String) Human-readable name shown in the OpenMetadata UI.
- `enable_streamable_logs` (Boolean) Whether the workflow streams logs back to the OpenMetadata server. Defaults to false.
- `logger_level` (String) Log level used by the ingestion workflow. One of DEBUG, INFO, WARN or ERROR.
- `raise_on_error` (Boolean) Whether the workflow fails instead of reporting partial errors. Defaults to false.
- `service_type` (String) Type of the referenced service, for example databaseService or dashboardService. Defaults to databaseService and is fixed at creation, so changing it replaces the pipeline.
- `source_config` (String) Source configuration as a JSON object string, for example {"type": "DatabaseMetadata"}. Its shape depends on pipeline_type.
