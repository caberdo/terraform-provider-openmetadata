# openmetadata_learning_resource Resource

Manages an OpenMetadata learning resource. A learning resource is a piece of academy content, such as an article or a video, tagged with the categories and UI contexts where it should appear.

## Example Usage

```terraform
resource "openmetadata_learning_resource" "data_governance_101" {
  name          = "data_governance_101"
  resource_type = "Article"
  display_name  = "Data Governance 101"
  description   = "Introduction to the data governance programme."
  categories    = ["AI", "DataGovernance"]
  difficulty    = "Intro"
  status        = "Active"

  estimated_duration   = 15
  completion_threshold = 0.8

  contexts = [
    {
      page_id      = "home"
      component_id = "learning"
      priority     = 1
    },
  ]

  source = [
    {
      url      = "https://example.com/academy/data-governance-101"
      provider = "user"
    },
  ]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import by UUID.
terraform import openmetadata_learning_resource.data_governance_101 1f6a3a52-8d34-4f4b-9d0f-2f1c1c1c1c1c

# Or import by fully qualified name, which equals the resource name.
terraform import openmetadata_learning_resource.data_governance_101 data_governance_101
```
